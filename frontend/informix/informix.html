Hop to another host

Tunnels from the currently connected host to another one in the same VLAN, without going back through the jump servers. Loading an environment again is required on the new host afterward. If you see an "Administratively prohibited" error, the current host is blocking SSH port forwarding (AllowTcpForwarding). Use a jump-server reconnection or a different gateway.
